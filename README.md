# openclaw-bailian

Realtime voice and speech-to-text plugins for [OpenClaw](https://github.com/openclaw/openclaw) Talk,
powered by Alibaba Bailian (DashScope).

| Package | What it does |
| --- | --- |
| [`openclaw-bailian-realtime`](./openclaw-bailian-realtime) | Realtime speech-to-text (dictation) for Talk |
| [`openclaw-bailian-voice`](./openclaw-bailian-voice) | Qwen-Audio-Realtime speech-to-speech voice provider for Talk |

Both need a DashScope API key. See each package README for setup.
